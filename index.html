03 — Install

Up and running in two minutes.

Five steps, nothing more.

.minecraft/mods/zero-client.jar
  1. 1111

    Install Java

    Java 21 or newer is required for current Minecraft versions.

  2. 2222

    Install Fabric Loader

    Run the Fabric installer and create a profile for your game version.

  3. 3333

    Download Zero Client

    Get the latest .jar with the button below.

  4. 4444

    Add it to your mods folder

    Drop the file in .minecraft/mods, next to Fabric API.

  5. 5555

    Launch the game

    Select the Fabric profile and start Minecraft.

Ready when you are.

04 — FAQ

Before you download.

Short answers to the usual questions.

Zero Client is built for Minecraft Java Edition on the Fabric Loader. Each release states the exact game version it was built for, so grab the build that matches your install.

Java 21 or newer, Fabric Loader and Fabric API, plus the Zero Client .jar in your mods folder. The Install section above walks through it in five steps.

It runs in multiplayer, but many servers forbid combat and movement modules and will ban you for using them. Check the rules before you join and only use modules where they are allowed. Singleplayer and your own worlds are the easy place to try everything.

Zero Client is open source, so you can read every line and build the .jar yourself. Only download from the official releases page; a file from anywhere else is not ours.

No. It is a Fabric mod for Minecraft Java Edition on desktop only.

Open an issue on the GitHub repository. Include your game version, your Zero Client version and what you were doing when it happened.
